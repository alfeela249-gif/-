# المزرعة السودانية 3D

نموذج أولي مجاني للعبة زراعة ثلاثية الأبعاد يعمل في متصفح الهاتف والكمبيوتر.

## الموجود حالياً
- مشهد ثلاثي الأبعاد للمزرعة وحقل ومحاصيل ومخزن وأشجار وخزان مياه.
- جرار قابل للقيادة مع أزرار لمس.
- شخصية مزارع يمكن النزول بها من الجرار والعودة إليه.
- زراعة تجريبية داخل الحقل.
- ثلاث زوايا للكاميرا.
- واجهة عربية، مع تنبيه لتدوير الهاتف للوضع الأفقي.

## التشغيل
افتح index.html عبر خادم ويب حديث مع اتصال إنترنت لتحميل مكتبة Three.js من CDN.

## النشر المجاني
من إعدادات المستودع في GitHub افتح Pages، واختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واحفظ. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.
